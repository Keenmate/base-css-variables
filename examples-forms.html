Every field in pure-admin and in every component reads the same input tokens, so a select in web-multiselect, a date field in web-daterangepicker and a pure-admin text box line up: same height scale, border, focus ring, placeholder and icon colour. The checkbox has one render method for everyone (README → Checkbox render method).

FO01 · Text field states

The first field is live: hover it and click into it. The rest are pinned to one state.

FO02 · Field heights

Five heights, unitless × --base-rem. A component's size attribute picks one, so an sm multiselect and an sm pure-admin input are the same height.

FO03 · Dropdowns and tooltips

A dropdown panel uses the main surface with its own border and shadow tokens, and the item states from the item-state model (hover, selected tint, focused ring). The tooltip is the inverse of the surface: dark on a light page, light on a dark one.

FO04 · The checkbox

Two knobs: --base-checkbox-scale sizes the box, its border and its corners (all through calc); --base-icon-check-size sizes the glyph as a percentage of the box. Never transform: scale(): it moves the box to its own layer, which snaps the glyph to whole pixels, so the tick drifts from row to row. Compare the columns at 1.25 or 1.5.
