One loading indicator for the pure-admin app and every component. Shadow DOM lets only custom properties in, so the loader is four tokens and each consumer draws it with the same four lines (mask + currentColor + a rotate animation). Swap --base-loader-icon once and every loader changes. Single colour: the icon is a mask.

1. In text, sized by em

--base-loader-size: 1.25em — the loader follows the font size of the line it sits in. Colour is currentColor.

3. Reduced motion

Under prefers-reduced-motion: reduce the four --base-duration-* become 0s but --base-loader-duration slows to 1.5s — a loader that stops reads as "frozen". An SVG that animates itself keeps its own timing: it doesn't read --base-loader-duration, so only a @media rule inside the SVG can slow it (see the test notes in e2e/loader.spec.ts).
