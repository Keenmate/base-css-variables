# Base CSS Variables 2.1.0 — Release Notes

**Released:** 2026-11-26 · **Stable** (`npm install @keenmate/base-css-variables`)

These notes cover the changes since **2.0.2**, the last version on npm.

Two new tokens: `--base-container-narrow` (`480px`) and `--base-container-medium` (`768px`), the
lines web-components-core's responsive `container` axis uses for a component's own width. Nothing
existing changed, so this is a drop-in update.

The exhaustive, per-change list is in
[`CHANGELOG.md`](https://github.com/keenmate/base-css-variables/blob/prod/CHANGELOG.md) (section
2.1.0); this document is the upgrade guide and the highlights.

## Requirements

| Package / platform | Version |
|---|---|
| `@keenmate/pure-css` | mirrors the tokens as `$base-container-narrow` / `$base-container-medium` |
| `@keenmate/web-components-core` | reads them for the responsive `container` axis (works without them, same defaults) |
| Browsers | Chrome / Edge 119+, Safari 16.4+, Firefox 128+ (unchanged) |

## Upgrade checklist

**Apps and themes**

- [ ] Nothing required: no token was renamed, removed or re-valued.
- [ ] Optional: set `--base-container-narrow` / `--base-container-medium` on a section (e.g. a
      sidebar) to move the narrow / medium / wide lines for the components inside it.
      ([details](#container-sizes))

**Component authors**

- [ ] If your component uses core's responsive rules, key them on `container: { narrow, medium }`
      and let core read the tokens; don't hard-code `480px` / `768px`. ([details](#container-sizes))
- [ ] Bump the `@keenmate/base-css-variables` devDependency to `^2.1.0` so `base-contract-check`
      knows the new names (otherwise C1 reports them as unknown).

## New features

### Container sizes

The breakpoints (`--base-breakpoint-*`) are about the window. A component inside a sidebar can be
narrow on a wide screen, so web-components-core's responsive rules gained a `container` axis keyed
by the component's own width:

| Width | Size |
|---|---|
| below `--base-container-narrow` (`480px`) | `narrow` |
| below `--base-container-medium` (`768px`) | `medium` |
| otherwise | `wide` |

Core reads the values *at the element*, so a section can change them for what it contains:

```css
.sidebar {
  --base-container-narrow: 320px;
  --base-container-medium: 560px;
}
```

They're plain `px` like the breakpoints, not rem multipliers, and live in `:root` (inputs).
