Icons are inline SVG data URIs (Lucide glyphs). Components draw them as a mask over currentColor, so an icon takes the text colour of wherever it sits, and the mask works inside shadow roots where a page's icon font or sprite can't reach. Swap a token and the glyph changes in pure-admin and every component.

IC01 · The icon set

Aliases follow their source with var(): --base-icon-clear and --base-icon-remove follow --base-icon-close. The draw rule:

.icon {
  inline-size: 1em;
  block-size: 1em;
  background: currentColor;
  mask: var(--base-icon-close) center / contain no-repeat;
}

IC02 · Swap an icon everywhere

Each select sets one token on :root. Open the multiselect: the chip remove ✕ and the clear button follow --base-icon-close; the dropdown arrow and the tree's expander are --base-icon-chevron.

A replacement chevron must point right, like the default: components rotate it 90° when open (the multiselect's arrow always, a tree row when expanded). A glyph drawn pointing down ends up pointing left.

IC03 · Palette slots

Nine categorical colours for things that need to be told apart but carry no meaning: chart series, tags, avatars, calendar categories. They are not roles: no hover steps, no tints. Each has a text-on-fill token picked by contrast.
