Font sizes, spacing, radii and field heights are stored as bare numbers and multiplied by one unit: calc(var(--base-font-size-sm) * var(--base-rem)). pure-admin sets the unit to 10px (its html font size), so 1.4 is 14px. Change --base-rem on any element and everything inside scales together: a compact grid, a roomy dialog.

SZ03 · Breakpoints

--base-breakpoint-mobile and --base-breakpoint-tablet are the widths where layouts switch. @media can't read var(), so they are read from JavaScript (pure-css's config, web-components-core's env.breakpoint); pure-css compiles the same widths from SCSS. Resize the window.

const css = getComputedStyle(document.documentElement);
const mobile = parseFloat(css.getPropertyValue('--base-breakpoint-mobile'));  // 768
const isMobile = matchMedia(`(max-width: ${mobile - 0.02}px)`).matches;
