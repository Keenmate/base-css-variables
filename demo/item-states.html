Item states

One shared look for list options, tree rows and grid rows. Every component on this page reads the same --base-selected-* / --base-focused-* tokens, so the controls below re-theme all of them at once.

The model (Windows Explorer)

A plain click makes an item both focused and selected, so it shows the tint and the solid focus ring. Ctrl+click a second item to see them apart: the tint stays, the ring moves.

focused
The one item the keyboard / mouse cursor is on. Arrows move it. Inset ring: --base-focused-bg / -text-color / -outline.
selected
The click / Ctrl / Shift-click (Shift+arrow) set, 0..n items. Accent tint: --base-selected-bg / -bg-hover / -text-color / -outline.
checked
The checkbox-checked items, shown by the checkbox only, so there are no row tokens. With checkboxes off, checked mirrors selected.
