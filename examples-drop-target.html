Before 2.0.0-rc06 a drop target borrowed the primary tint, which is also what --base-selected-bg is. On the left, "Music" is selected and "Videos" is the row you're dropping onto: only a 1px outline tells them apart. On the right, the same picture drawn from --base-drop-target-bg / -bg-active / -border-color — the success tint by default, so the drop target stands out from the selection. Pick a theme override to see that only drops change. You can also drag the rows, the header cells and a file from your desktop.
